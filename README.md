# Hastha portfolio

One-page responsive portfolio for Hastha. Built with plain HTML, CSS, and JavaScript so it can be hosted on GitHub Pages without a build step.

## Local preview

Open `index.html` in a browser, or serve this folder with any static web server.

## GitHub Pages

Publish the root of the repository from the `main` branch in **Settings → Pages**. No build action is required.

Project visuals are illustrative CSS mockups, not screenshots of the finished applications.
